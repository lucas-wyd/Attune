# Third-Party Notices

Attune has not incorporated third-party source code as of 29 August 2026.

Researching or linking to another project does not mean its code was reused. When third-party code or assets are introduced, add an entry below in the same change.

## Entry template

### Project or component name

- Source: full repository and file URL
- Revision: exact commit, tag, or release
- License: SPDX identifier and link to the reviewed license text
- Material used: files, functions, algorithms, assets, or other portions incorporated
- Modifications: concise description of Attune's changes
- Included notices: location of copied copyright, attribution, and license notices
- Obligations: source, distribution, attribution, or other requirements that apply

Do not add code whose reuse rights are unclear. License compatibility questions should be resolved before incorporation, not after release.
